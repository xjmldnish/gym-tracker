# 🏋️ Gym Workout Tracker

A personal gym session tracker built with React. Log your workouts, track your Personal Records (PRs) automatically, and visualise your weight progression over time with charts.

## 🌐 Live Demo
[Click here to view the live app](YOUR_VERCEL_URL)

## 📸 Features
- 💪 Log workouts by muscle group and exercise with sets, reps, and weight
- 🏆 Automatic Personal Record (PR) detection with instant alert notification
- 📈 Weight progression chart per exercise (Recharts)
- 📅 Full workout history with delete support
- 💾 All data persists across sessions using localStorage
- 🎯 Covers 6 muscle groups — Chest, Back, Legs, Shoulders, Arms, Core

## 🛠️ Built With
- React (Hooks — useState, useEffect)
- Recharts
- localStorage API
- CSS3
- Vercel (Deployment)

## 🚀 Getting Started
```bash
git clone https://github.com/xjmldnish/gym-tracker.git
cd gym-tracker
npm install
npm start
```
